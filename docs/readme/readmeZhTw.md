---

## 主要能力

- **本地部署**：專案與素材保存在自己的裝置或伺服器，支援桌面、Android、Docker 與伺服器部署，無需登入註冊。
- **無限畫布**：在同一畫布中組織劇本、角色、場景與影片片段。
- **MCP 與插件**：透過 MCP 連接外部工具，用插件擴展節點、工具與技能。
- **自由接入模型**：設定第三方 API，或接入本地 ComfyUI 與 LLM。
- **多語言介面**：支援 21 種介面語言。
