## Highlights

- **Local deployment**: Projects and assets stay on your own device or server, with desktop, Android, Docker and server options, no sign-in required.
- **Infinite canvas**: Organise scripts, characters, scenes and video clips on a single canvas.
- **MCP and plugins**: Connect external tools over MCP and extend nodes, tools and skills with plugins.
- **Bring your own models**: Configure third-party APIs, or connect a local ComfyUI instance and LLM.
- **Multilingual UI**: 21 interface languages.
