## 主な機能

- **ローカル実行**：プロジェクトと素材は自分の端末やサーバーに保存されます。デスクトップ、Android、Docker、サーバーに対応し、ログイン登録は不要です。
- **無限キャンバス**：台本、キャラクター、背景、動画クリップを 1 枚のキャンバスで整理します。
- **MCP とプラグイン**：MCP で外部ツールと接続し、プラグインでノード・ツール・スキルを拡張します。
- **任意のモデルを接続**：サードパーティ API、またはローカルの ComfyUI と LLM を利用できます。
- **多言語 UI**：21 言語のインターフェースに対応します。
